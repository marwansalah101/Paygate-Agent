## PayGate — Portfolio Summary

**What it is:** A pitch/pilot demo for a Saudi payment gateway (KSA-focused Stripe/Geidea competitor) — AI-powered merchant onboarding that compresses a 15-minute, 25+ field process down to under 3 minutes across 2 phases.

**How:** AI orchestrates Saudi gov verification APIs (Wathiq, Yakeen, Nafath) in parallel, auto-fills merchant data, extracts IBANs from uploaded docs, and auto-classifies business category from a URL — all wrapped in KYC/AML compliance infrastructure (PDPL, SAMA-style screening).

**Stack:** Next.js/React/TypeScript frontend, Python FastAPI backend, Claude (Haiku for text, Sonnet for vision) via OpenRouter.
